How to read the statuses

LIVE · MESH = non-retained PUBLISH observed on msh/.../2/e/... (Protobuf content is not validated). LIVE / OTHER = live traffic on other topics. ONLINE / IDLE = CONNACK and SUBACK accepted, but no live message received during the observation window. TCP, DNS, TLS and ACL errors are reported separately. One failed probe does not establish a global outage.

The directory uses only operator-published public community accounts; it does not store private credentials, MQTT payloads, node identifiers or private broker information. To add or correct a server, open a pull request. Source on GitHub ↗
